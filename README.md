# ПУСТОТА

Браузерная 3D-игра про альтернативную эволюцию. Ты — клетка в шумовой «пустоте».
Никаких меню прокачки: тело и мир меняются от того, **как ты играешь**.
Стек: TypeScript + Vite + Three.js. Ноль ассетов — всё процедурное.

## Как запустить

```bash
npm install
npm run dev      # разработка
npm run build    # прод-сборка в dist/ (≤ 2 МБ gzip)
```

Онлайн: https://meek8lead.github.io/slopspore/

## Управление

| Действие | Клавиши |
|---|---|
| Двигаться | `W A S D` или стрелки |
| Подняться | `Space` или `Q` |
| Опуститься | `Shift` или `E` |

Раскладка не важна: клавиши привязаны к физическим кодам (`KeyW`…),
поэтому работают и в русской (`ЦФЫВ`), и в любой другой раскладке.

## Как играть и чего ждать

**Ешь.** Касание мелких светящихся икосаэров = поглощение. Еда поглощается
контактом, никаких кнопок нажимать не надо. Голод — сигнал, что пора двигаться.

**Эволюция — это привычки.** Игра молча следит за тем, что ты делаешь:
гонишься за добычей → вырастают шипы; стоишь на месте в химических зонах →
тело покрывается «пушком» хемосинтеза; держишься рядом с существами, не трогая
их → симбиотическое тёплое свечение; убегаешь от крупных → манёвренность.
Всё 11 осей поведения плавно morph-ят тело через шейдер. Меню выбора веток нет и не будет.

**Делись.** Накопи энергию выше ~85% и массу — клетка вспыхнет и разделится.
Каждый митоз тихо поднимает скрытый уровень экосистемы `ecoLevel`. Он только растёт.

**Мир подстраивается — но молча.** Вокруг тебя есть невидимый «пузырь», где
экосистема выравнивается под твой прогресс: чем ты сильнее, тем плотнее еда,
жирнее куски, и при `ecoLevel > 0.3` из шума начинают проступать **крупные
шипастые существа** — медленные, опасные (бьют при касании), но дающие втрое
больше энергии. Убил существо — его труп оседает: падаль (детрит) можно съесть
самому, а мелкие NPC слетаются к ней — вокруг трупа легко устроить засаду.

**Голодание видит мир.** Долго голодал — еда respawn-ится гуще. Получил урон —
хищников временно меньше. Доминируешь — сложность подрастает. Всё в узких
пределах ×0.5…×2, «режима бога» не бывает.

**Автотрофия — тупик без партнёров.** Фотосинтез/хемосинтез дают энергию в
светлых/химных зонах, но только до 75% заряда — делиться нельзя. Либо ешь,
либо выращивай симбиоз с существами (он пробивает потолок). Оседлость делает
тело медленным — каждый выбор имеет цену.

**Ощущай, не читай.** HUD нет. Боль = тело гаснеет к багровому и дрожит.
Яд = зелёное марево. Броня = «скорлупа». Голод = тусклое тело. Прогресс
измеряется телом и плотностью мира. Экран отладки (F3-подобный debug-overlay) —
временный, для разработчика.

**Сохранися.** Прогресс автосейвится в localStorage каждые 5 секунд
(уровень, масса, энергия, позиция, поведение, популяция). Закрыл вкладку —
вернулся продолжил.

## Визуал

Low-res рендер (270p) + nearest-upscale + Bayer-dither + scanlines + лёгкая
хроматика + 6-bit crunch — вайб «образовательного видео с VHS 90-х».
Процедурные Canvas-текстуры («пластилиновая кожа» клеток, мягкий FBM-фон,
перекрашиваемый из циклящейся 16-цветной палитры). Никаких внешних файлов.

## Карта исходников

```
src/
├── main.ts            # game loop и оркестрация
├── config.ts          # ВСЕ константы — единая точка правды
├── core/              # rng, save/load (localStorage, версионированный JSON)
├── render/            # палитра + пост-пайплайн (inline GLSL)
├── world/             # medium (поля среды), eco (раббербенд+реактивность),
│                      # background, particles (еда+детрит), textures (процедурные карты)
├── entities/          # player (шейдер морфологии), behavior (EMA+pulse), npc (+NpcManager)
└── ui/debug.ts        # временный debug-overlay
```

## Инварианты (нарушение = провал)

Ноль меню эволюции · ноль дискретных стадий (ecoLevel — float) · ноль HUD в
релизе · ноль ассетов · WebGL2 · bundle ≤ 2 МБ gzip · ecoLevel только растёт ·
поведение — только EMA + pulse · все константы в config.ts.
